## 重要编码说明

现有CLEAR和弱参考文件均使用`0/1`，且GeoTIFF元数据中的NoData也为0。因此，不能仅凭GDAL NoData掩膜解释业务语义：CLEAR中的0表示未通过质量筛选，弱参考中的0表示非候选区/背景。正式空间模块应把有效观测掩膜作为独立输入，并在新产物中使用独立valid mask或不与背景冲突的NoData编码。

## 8175000平方米的来源

弱参考中共有81750个值为1的10 m像元。按每像元100平方米计算得到8175000平方米。该值是2023年耕地弱参考候选面积，没有叠加2025年CLEAR掩膜，也不是模型推理得到的水稻面积，只能作为演示或空间统计校验值。
