# 数据清洗与质量规则

## 遥感影像

1. 仅保留与示范区相交且覆盖水稻种植季的场景；
2. 优先采用目录云量不高于 20% 的场景，最终以分析区内有效像元比例为准；
3. 统一使用同一产品级别和波段定义，不混合 TOA 与地表反射率；
4. 对云、云影、无效像元分别编码，禁止直接填 0；
5. 同一日期同一瓦片去重，保留处理级别更高、质量更完整的记录；
6. 每景必须经过 OGE `getCoverage` 权限测试后，才可标记为 `read_verified`；
7. 时序识别至少覆盖前期灌水/移栽、中期旺盛生长和后期成熟三个窗口。

## 边界

1. 修复自相交、多部件异常和空几何；
2. 统一唯一编号，检查重叠和空缺；
3. 保存原始坐标系和转换记录；
4. 行政边界不得表述为真实供水服务范围。

## 作物历与灌溉定额

1. 作物、地区、生育阶段和年份必须匹配；
2. 定额必须明确单位、来源、适用时期和版本；
3. 分阶段定额直接用于对应阶段计算，不与全生育期定额重复叠加；
4. 未经确认的建议值标记为 `draft`，不得作为最终业务结论。

## 气象数据

1. 统一时间基准和单位，记录累计/平均/瞬时变量含义；
2. 月尺度降水不得直接等同于田间有效降水；
3. 首期降水主要用于背景解释和关注等级，不在缺少依据时直接修正定额；
4. 缺测、未覆盖、有效零值分开编码。
