# 江夏区分析网格

`jiangxia_5km_grid_utm50n.geojson` 是依据公开江夏区边界生成的 5 km × 5 km
规则网格，坐标系为 EPSG:32650。网格仅用于组织 OGE 遥感裁剪、特征计算和任务
追踪，不替代行政区或灌区边界。

- 有效网格：107 个；
- 核心网格（区内覆盖率不低于 50%）：83 个；
- 边缘网格：24 个；
- 覆盖率采用 250 m 间隔采样近似计算；
- 生成脚本：`scripts/build_jiangxia_grid_catalog.py`；
- 属性清单：`data/catalog/jiangxia_5km_grid.csv`。

平台计算时使用完整矩形网格进行裁剪，面积汇总时仍须与江夏区正式边界相交，避免
把边缘网格的区外部分计入江夏区结果。
