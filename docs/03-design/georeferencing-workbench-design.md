# 影像配准工作台设计

## 目标与边界

现有灌区 PNG 是已经拼接、裁切的遥感影像，但缺少坐标参考和仿射变换。工作台的首要目标不是重新制作遥感底图，而是通过人工控制点恢复“图像像素坐标到地图坐标”的可追溯关系，并将已提取的像素边界转换为可在 WebGIS 中检查的 WGS 84 草稿边界。

首版结果一律标记为 `unverified`。只有控制点、变换方法、残差和人工复核记录完整后，才能进入管理单元导入流程。原始 PNG 和像素边界不被覆盖。

## 智能辅助配准设计

自动化采用“建议而非裁决”的原则。用户先在目标地图缩放到大致区域，系统获取当前范围的参考卫星影像，以 SIFT 局部特征建立初始匹配，再使用仿射 RANSAC 剔除明显错误匹配。候选点按源图网格分散选取，避免全部集中在单一区域。

候选点必须经过以下流程才能参与拟合：

1. 系统生成候选并标记为`review_required`；
2. 用户在双视图中逐点核对，可以确认或删除，也可以人工补点；
3. 未确认候选存在时，正式拟合按钮保持禁用；
4. 确认后仍需检查空间分布、逐点残差和边界叠加效果；
5. 自动候选、人工确认和最终配准结果分别记录，自动推荐绝不直接产生`verified`边界。

首版使用传统局部特征，原因是运行轻量、解释清楚且易于本地部署。若跨年份、跨传感器影像导致局部特征不足，再评估 MatchAnything、LoFTR 或 DINO 系列深度匹配模型；增强模型仍只负责候选推荐，不绕过人工确认。

候选匹配采用OpenCV与LightGlue等成熟实现中常见的分层筛选思路：先进行Lowe最近邻距离比率检验，再要求源图到参考图、参考图到源图满足双向最近邻一致性，最后通过仿射RANSAC进行几何验证。该流程用于减少重复纹理造成的单向误匹配；最终配准模型仍使用用户确认后的控制点重新计算。

当前报告中的控制点误差按拟合后投影坐标残差计算，属于控制点内符合度。按照ASPRS位置精度标准与USGS遥感系统评价建议，真实位置精度应通过未参与模型求解、且来源精度更高的独立检查点计算RMSE。本原型现阶段没有独立测量点，因此不将拟合残差解释为绝对定位精度。

## 首版方法选择

源图看起来已经完成正射和拼接，当前主要缺失整体位置、旋转、尺度及轻微剪切信息，因此首版采用二维仿射模型：

```text
E = a0 + a1*x + a2*y
N = b0 + b1*x + b2*y
```

其中 `(x, y)` 是以图像左上角为原点的像素坐标，`(E, N)` 是投影坐标。海门区默认使用 WGS 84 / UTM 51N（EPSG:32651）进行拟合和误差计算，避免直接在经纬度上计算“距离”。输出边界再转换为 WGS 84（EPSG:4326）。

- 3 个有效且不共线的控制点：求解恰好确定的仿射模型；
- 4 个及以上有效控制点：采用最小二乘拟合；
- 推荐 6–10 个控制点，覆盖四角、中心和形状转折区域；
- 道路交叉口、桥梁端点、渠河交汇点等稳定地物优先；
- 避免控制点集中在局部或近似排成一条直线。

首版不使用薄板样条（TPS）。只有在仿射残差呈现明确、稳定的局部形变，且增加和优化控制点仍无法解释时，再将 TPS 作为增强方法。

## 计算与质量输出

后端核心必须输出：

1. 仿射系数及使用的源/目标坐标系；
2. 每个控制点的预测位置、东西和南北方向残差、平面误差；
3. RMSE、最大误差、有效控制点数量与矩阵秩；
4. 转换后的 WGS 84 草稿边界；
5. 方法版本、输入图像尺寸和控制点快照。

质量阈值不直接替代人工判断。系统可以提供提示，但不应仅凭一个阈值自动把边界标记为 `verified`。必须同时检查控制点空间分布、叠加预览和关键地物是否对齐。

## 交互流程

1. 选择源图和对应的像素边界；
2. 在源图中点击一个稳定地物，再在地图中点击同一位置；
3. 重复建立控制点，可禁用或删除错误点；
4. 达到最少点数后拟合，查看逐点误差和总体 RMSE；
5. 在卫星底图上叠加转换后的边界，调整控制点并重新计算；
6. 保存配准会话与版本；
7. 人工确认后，将结果作为 `unverified` 管理单元草稿导入，不覆盖历史版本。

## 分阶段实现

### 阶段一：可信计算内核

- 仿射拟合、输入校验、投影转换；
- 逐点残差和总体误差报告；
- 像素 GeoJSON 到 WGS 84 的转换；
- 正常、重复点、共线点和非法数据测试。

### 阶段二：配准界面

- 源图与 OpenLayers 地图双视图；
- 成对控制点采集、编号、启停和删除；
- 拟合报告与边界叠加预览；
- 会话自动保存和 JSON 导入导出。

### 阶段三：业务接入

- 配准会话版本化存储；
- 经人工确认后调用管理单元导入接口；
- 保存来源、质量说明、复核人和版本关联；
- 后续支持 GeoTIFF 导出和更复杂的变换模型。
