# 灌区裁切影像边界恢复记录

## 数据性质

现有悦来灌区和常乐灌区原图为白色背景上的裁切影像，不是GeoTIFF。PNG内不包含CRS、仿射变换或经纬度范围，目录中也没有PGW、WLD、PRJ等配套文件。LabelMe JSON及`labels_mask`/`labels_vis`描述水稻地块标签，不是灌区边界。

## 地点核对

- 悦来灌区：江苏省南通市海门区，公开名录设计灌溉面积11.59万亩。
- 常乐灌区：江苏省南通市海门区，公开名录设计灌溉面积6.58万亩。
- 来源：中型灌区公开名录及南通市、海门区相关公开信息。

公开信息可确认灌区名称、所在区域和设计面积，但尚未发现可直接下载的官方灌区面边界。

## 像素边界提取方法

`tools/extract_clipped_irrigation_boundary.py`将与图像边缘连通的近白色像元识别为外部背景，取反后提取外轮廓，再以像素容差简化边界。这种方法不依赖图内的白色屋顶或亮地物，因为只把与画布边缘连通的白色区域视为背景。

## 当前结果

| 项目 | 悦来灌区 | 常乐灌区 |
| --- | ---: | ---: |
| 图像尺寸 | 8056×9111 | 7038×5578 |
| 连通轮廓数 | 1 | 1 |
| 简化后顶点数 | 257 | 146 |
| 轮廓像元面积 | 39,336,044 | 27,036,090.5 |
| 根据设计面积反推的像元尺度 | 约1.402米/像元 | 约1.274米/像元 |

反推像元尺度只用于检查轮廓数量级，不能代替原始遥感产品的真实分辨率与地理变换。

## 输出与使用边界

输出位于`data/derived/management_boundaries/unreferenced/`：

- `*.pixel-boundary.geojson`：像素坐标外轮廓；
- `*.footprint-mask.png`：裁切范围二值掩膜；
- `*.boundary-preview.jpg`：红线叠加检查图；
- `*.boundary-report.json`：提取参数和统计。

这些GeoJSON的坐标空间是左上角为原点的图像像素，不是WGS 84，不得导入正式PostGIS管理单元表。

## 配准所需条件

优先查找生成PNG时的原始GeoTIFF、GIS工程或转换参数。若无法获取，可以利用图内G40沪陕高速、互通、河道与主要道路选取控制点进行人工配准。配准后必须记录控制点、变换模型、残差和核验人，先作为`unverified`草稿边界，不直接声称为官方灌区界。
