# 悦来灌区模型适配试验记录 v1

## 1. 目的

本试验用于验证团队已有DeepLabV3+模型能否经过灌区样本适配后，产生可进入业务系统复核环节的候选地块成果。试验不把模型输出直接等同于正式水稻面积，也不在缺少分阶段灌溉定额时生成正式阶段需水量。

## 2. 数据与划分

- 场景：悦来灌区、常乐灌区。
- 输入：已裁切的RGB影像。
- 标签：团队已有人工地块掩膜。
- 图块：512×512像素。
- 空间隔离：以2048像素空间分组固定划分，避免相邻图块跨训练、验证和测试集合。
- 数量：训练202个、验证40个、测试42个。
- 正样本图块：训练99个、验证21个、测试12个。
- 固定划分：`data/splits/irrigation_rgb_v1.json`。
- 输入统计：`data/statistics/irrigation_rgb_v1.json`。

当前只有两个灌区场景，测试结果主要反映同区域空间外推能力，尚不能证明跨灌区、跨年份泛化能力。

## 3. 模型与训练

- 架构：DeepLabV3+。
- 编码器：ResNet50。
- 初始化权重：`outputs/deeplabv3plus_resnet50_trial5/best.pt`。
- 原权重SHA256：`61b64106956727bcd66a79df588c1afcf985feb66958950a57464b627943fe26`。
- 适配配置：`configs/deeplabv3plus_irrigation_rgb.yaml`。
- 最佳轮次：第5轮。
- 适配权重SHA256：`73d3c81f0f656e791b214f5a289555a2639d2d6cc1de04c7a500215d8faf0118`。

本次训练复用已有模型表征能力，再用灌区样本进行领域适配，不属于从零训练新模型。

## 4. 阈值选择与独立测试

阈值只在验证集上选择。对0.05至0.95的候选阈值按全局IoU比较后，选择0.60。锁定阈值后，在测试集上只执行一次正式评价。

| 数据集合 | IoU | F1 | Precision | Recall | Accuracy |
| --- | ---: | ---: | ---: | ---: | ---: |
| 验证集（阈值0.60） | 0.2631 | 0.4166 | 0.5148 | 0.3499 | 0.9268 |
| 独立测试集（阈值0.60） | 0.3262 | 0.4920 | 0.4027 | 0.6320 | 0.9290 |

测试集包含较多无正类图块，因此以全局像元指标为主，不用单图IoU中位数代表整体能力。

## 5. 悦来整图复核

适配模型使用512像素图块、128像素重叠和概率加权拼接完成8056×9111影像推理，输出带EPSG:32651空间参考的概率图和候选掩膜。

| 项目 | 结果 |
| --- | ---: |
| 人工参考面积 | 10,926.52亩 |
| 模型候选面积 | 11,587.36亩 |
| 面积差 | +660.84亩 |
| 整图IoU | 0.2084 |
| 整图F1 | 0.3449 |
| 整图Precision | 0.3351 |
| 整图Recall | 0.3554 |

整图面积接近不代表空间位置准确。误差图仍显示明显漏检和误检，而且整图包含参与训练的空间分组，所以该结果只用于地图审查、面积统计链路联调和问题定位。

## 6. 进入业务链路的条件

本版本状态固定为`review_required`，按以下方式使用：

1. 模型输出作为候选地块掩膜，并携带模型版本、权重哈希、阈值、数据版本和质量指标。
2. 面积统计必须同时引用有效观测掩膜和管理单元边界。
3. Web端明确显示“模型候选面积”和质量说明，不能显示为最终核定水稻面积。
4. 用户复核或修正后形成新版本，保留原模型版本及修订关系。
5. 分阶段灌溉定额缺失时，业务流程停留在参数待确认状态，不生成正式阶段需水量和关注等级。

## 7. 下一步

- 把适配模型运行清单和候选掩膜登记为版本化遥感成果。
- 由空间统计服务按悦来管理单元重新计算候选面积，消除脚本与业务后台之间的手工数值传递。
- 补充更多灌区、年份和影像条件，建立真正独立的跨场景测试集。
- 对人工标签口径进行复核，明确其代表水稻地块、当季种植地块还是更宽泛的耕地候选区。
