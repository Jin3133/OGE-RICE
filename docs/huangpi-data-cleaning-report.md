# 黄陂区武汉一号水稻识别数据初步清洗报告

## 1. 示范区结论

首选区域为 **湖北省武汉市黄陂区**，区域中心可暂按
**114.37°E，30.88°N** 表示。最终分析边界以黄陂区行政边界 GeoJSON 为准，中心坐标
只用于地图定位，不能替代边界。

选择黄陂区并非单纯因为赛事平台与武汉有关，而是因为它能够在同一行政区内覆盖明显的
地貌和农业场景梯度。黄陂区北依大别山南麓、南邻长江，整体北高南低，形成西北低山、
东北丘陵、中部岗状平原和南部滨湖平原四级阶梯；区域内河湖、水库、渠系和耕地并存，
适合测试水稻与林地、水体、居民地、旱地及阴影的混淆。

官方材料还将区域概括为“三分半山、一分半水、五分田”，并指出耕地主要集中于中部，
林地集中于北部。这使“按地形分层抽样”具有明确的区域依据，而不是主观拼接场景。

## 3. 清洗规则

1. **区域一致性**：只保留中心点和影像范围与黄陂区相交的场景；行政区检索命中但主要
   覆盖区外的影像在下一步根据 footprint 再剔除。
2. **地貌完整性**：核心集必须同时覆盖北部低山丘陵、中部岗状平原、南部滨湖平原，
   并保留一个城乡交错困难场景。
3. **季相一致性**：主体空间对比采用 2025-10-08 与 2025-10-28 两个相近时段；两者相差
   20 天，建模前必须检查收获进度差异，不能直接作为无差别同日镶嵌。
4. **早季辅助**：2024-06-14 三景仅用于水田水体特征、早季识别和时相对照，不与 2025
   年影像直接进行年度变化解释。
5. **重复控制**：同日期、相邻轨带且重叠度高的影像仅在能补足边缘覆盖或用于拼接质量
   检查时保留。
6. **质量控制**：目录云量为 0% 不等于局部绝对无云。每景仍需检查薄云、阴影、条带、
   无效值、辐射异常、几何错位和边缘黑区。
7. **模型约束**：只有完成 OGE 开发中心小范围读取和波段核验的影像才能由
   `catalog_verified` 升级为 `compute_verified`。

## 5. 当前边界与下一步

这是一份 **目录级初步清洗结果**，尚不是可以直接训练的最终数据包。下一步必须完成：

1. 在开发中心逐景执行小范围 `getCoverage`，确认产品调用权限、coverage ID 和波段名；
2. 获取每景 footprint，与黄陂区边界求相交比例，剔除仅擦边命中的场景；
3. 调用 DEM 将核心场景划分为低山、丘陵、岗地和平原，验证地形分层是否真实落入影像；
4. 生成统一坐标、统一波段顺序、统一数值尺度和 NoData 规则的预处理结果；
5. 为各地形层分别建立水稻与非水稻验证样本，避免样本只集中在南部大田；
6. 比较 10 月 8 日与 10 月 28 日的物候差异，决定采用单期、双期特征还是分日期建模。

在上述步骤完成前，不把 13 景称为“最终训练集”，而称为“黄陂区代表性候选核心集”。
