# 开发路线

## 第一阶段：OGE 核心脚本

- 读取武汉一号融合影像。
- 调用 `whu-cultivated_land` 获取耕地候选区。
- 核验输出类型、类别值和地图渲染。
- 增加统计单元裁剪与面积统计。
- 将脚本发布为个人算法服务。

## 第二阶段：业务后台

- 调用 OGE 个人算法服务并跟踪任务状态。
- 保存区域、种植季、生育阶段、定额和成果版本。
- 按“面积 × 分阶段灌溉定额”计算参考需水量。
- 生成需水关注等级与重点区域清单。

## 第三阶段：Web 应用

- 复用官方 Vue 3 模板的鉴权和部署能力。
- 建设任务创建、地图展示、参数确认、重点区域和成果导出页面。
- 以 Docker 单容器形式部署到 OGE 第三方 Web 应用托管。

## 第四阶段：水稻专用模型增强

- 在确定的示范区补充水稻与非水稻样本。
- 对比规则法、轻量 U-Net 和候选预训练模型。
- 以独立样本的精确率、召回率和 F1 选择最终方案。
- 保持后台和前端接口不变，仅替换 OGE 识别服务。
