数据文件没有写入地理坐标、空间范围或实际像元分辨率，因此不能依据 TIFF 元数据将其直接定位到江夏，也不能严谨声明其具体米级分辨率。视觉检查表明，道路、单体建筑、田块边界等细节清晰，明显优于此前10米 Sentinel-2 数据，适合作为高分辨率分割基础数据。

## 对本项目的适用性

该数据集标签为“耕地”，并非“水稻”。样本中包含规则农田、不规则耕地、设施农业、果园或其他具有耕地形态的区域，因此不能把原有掩膜直接解释为水稻标签。

建议用途如下：

1. 训练武汉一号耕地分割基线，验证影像读取、增强、训练和推理链路。
2. 将耕地模型作为水稻分割模型的初始化权重或候选区域提取模块。
3. 从900张样本中筛选疑似水田样本，结合多时相 Sentinel-2 信息或人工判读重新标注 `rice`。
4. 以高分辨率影像确定地块边界，以时序影像辅助区分水稻和其他作物。

## 当前结论

该数据集可以解决“现有10米图像无法精细分割”的问题，并能够马上支撑耕地分割算法开发。但它不能单独解决水稻类别识别问题。项目下一步应先建立耕地分割基线，再进行水稻样本筛选和少量精标，避免从零训练高分辨率模型。
