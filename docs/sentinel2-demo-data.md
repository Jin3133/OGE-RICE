# 江夏 Sentinel-2 演示数据说明

更新时间：2026年11月11日

## 数据结论

首批业务闭环数据已经落地，共20份四波段GeoTIFF，覆盖江夏区4个代表性5 km样区和5个关键时相。所有文件均为500×500像元、10 m分辨率、EPSG:32650，波段顺序为B02、B03、B04、B08，并保留采集日期、场景编号、云量、样区编号和来源信息。每份影像同时配套20 m原始SCL和重采样至10 m的清晰像元掩膜。

这些数据具有真实坐标和像元面积，可以用于模型输入、分区面积统计、地图展示和业务接口联调。现有官方耕地训练切片不具备真实地理参考，不能替代本数据集承担面积核算。

- 四波段影像数量：20；
- SCL和清晰像元掩膜：各20份；
- 文件尺寸：全部为500×500像元；
- 波段数量：全部为4；
- 坐标系统：全部为EPSG:32650；
- 空间分辨率：全部为10 m；

## 当前适用范围

本数据集可以立即用于：

1. 验证带坐标影像的模型推理；
2. 输出继承真实坐标的候选区掩膜；
3. 按5 km管理网格统计平方米、亩和占比；
4. 组织多时相指数和时序特征；
5. 为Web地图和FastAPI接口提供演示成果。

当前不能直接用于宣称水稻识别精度，因为尚未完成水稻人工标注和独立验证。`JX5K_R05C04`作为规则农田比例较高的主要正样区，`JX5K_R07C05`以水体为主、作为困难负样本，其余两个样区用于混合农田和城郊破碎场景验证。水稻属性最终仍需人工标注或可靠参考资料确认。
