# OGE 耕地分割数据集质量审计

## 1. 审计对象

- 样本数：900 组影像与标签。
- 影像：512×512、3 波段、`uint16` TIFF。
- 标签：512×512、单波段、`uint8`，仅包含 0（背景）和 1（耕地）。
- 数据集官方任务：耕地二值语义分割，不是水稻种植识别。

## 2. 可以直接确认的质量情况

- 900 组影像与标签一一配对，尺寸一致。
- 没有空标签、全前景标签、非法标签值或完全重复影像。
- 耕地像元平均占比约 30.78%，中位数约 25.40%；最小约 5.04%，最大约 93.73%。
- 所有样本都包含一定数量的正负像元，可用于二值分割训练。
- 标签没有大量极小连通域，未发现明显的散点噪声问题。

## 3. 训练前必须处理的问题

### 3.1 零值无效区域

102 景影像包含超过 0.1% 的零值区域，93 景超过 5%，43 景超过 50%。可视检查表明这类区域主要是旋转或裁切形成的黑色无效边缘，而不是正常地物。

训练时应由三个波段共同生成有效像元掩码：三个波段均为 0 的像元不参与损失计算，也不参与指标统计。不能简单把黑边当作普通背景训练，否则模型容易学习到无效边缘特征，且评价指标会被大量简单背景抬高。

首轮验证集和测试集建议只保留有效覆盖率不低于 80% 的样本；低覆盖样本可留在训练集中作为增强数据，也可单独形成边缘场景测试集。

### 3.2 当前随机划分不适合最终成绩报告

当前 720/90/90 划分只用于打通代码。缩略特征检查发现少量高相似影像跨越不同集合，但高相似的一部分来自共同黑边，并不能直接认定为重复地块。

更关键的是，数据文件不包含坐标、原始景编号、采集时间或切片来源，因此目前无法按原始影像或地理区域进行严格分组。最终评估前应向平台确认样本来源关系；若无法取得，应至少按有效覆盖率与前景比例进行分层，并将疑似相似样本聚类后整组划分。

### 3.3 波段定义和归一化口径缺失

TIFF 内没有波段名称、空间分辨率、坐标参考、采集时间和反射率缩放说明。三个波段全局抽样统计如下：

| 波段 | 均值 | 标准差 | P2 | P50 | P98 |
|---|---:|---:|---:|---:|---:|
| Band 1 | 1021.95 | 288.28 | 0 | 1062 | 1428 |
| Band 2 | 1025.70 | 304.60 | 0 | 1057 | 1481 |
| Band 3 | 772.24 | 283.22 | 0 | 782 | 1309 |

由于零值黑边进入了全局分位数，不能直接使用上表的 P2 作为拉伸下限。模型输入应先排除全零像元，再统计训练集专用的逐波段均值与标准差。训练和推理必须使用同一组参数。

在平台确认波段顺序前，不能假定其为标准 RGB，也不能直接套用 ImageNet 的均值和标准差。

### 3.4 标签语义与本项目目标不同

官方元数据明确标注类别 1 为“耕地”，不是“水稻”。影像中也可看到不同类型农田、设施与城乡混合场景。因此该数据适合：

1. 验证本地分割训练、推理和部署链路；
2. 训练通用耕地分割基线；
3. 作为水稻模型的预训练或候选耕地区域提取模块。

它不能单独支撑“水稻种植面积识别”的业务结论。水稻识别仍需要水稻专用标签、物候时序数据，或至少在目标示范区补充人工核验样本。

### 3.5 标签中的 nodata 元数据不可直接采用

标签 TIFF 将 nodata 写为 0，但 0 同时又是合法的“背景”类别。训练代码不能依据标签文件的 nodata 字段屏蔽所有 0 值，否则会丢失全部背景监督。无效像元应由影像三个波段的全零区域独立判断。

## 4. 推荐的数据处理顺序

1. 保留原始 TIFF，不覆盖或改写官方数据。
2. 根据影像三波段全零条件生成有效像元掩码。
3. 仅使用训练集有效像元计算逐波段归一化参数。
4. 按有效覆盖率、耕地占比和相似样本组重新划分数据。
5. 使用裁剪、水平/垂直翻转、90°旋转及轻度光谱扰动进行增强；不要使用会破坏地块形态的强透视变换。
6. 损失函数采用 BCE 与 Dice 的组合，损失和 IoU/F1 均忽略无效像元。
7. 除总体 IoU/F1 外，单独报告完整覆盖样本、黑边样本和高/低耕地占比样本的结果。
8. 先训练 DeepLabV3+ 验证链路，再训练 SegFormer-B0 作为主模型。

## 5. 当前结论

该数据集足以启动“耕地二值分割”基线训练，整体标签结构和类别比例可用；但必须增加无效像元屏蔽、训练集专用归一化和更稳健的数据划分。它不能直接替代水稻专用训练数据，也不能在缺少波段与来源说明的情况下直接宣称为特定分辨率、特定地区或特定作物的数据成果。
