# 可复用资源评估

## 立即采用

### OGE 官方全栈模板

- 复用 Vue 3、Vite、接口鉴权、相对路径打包和 Docker 托管结构。
- 后台采用官方手册允许的 FastAPI 单进程替代方案。
- 不复用示例中的光谱曲线业务页面和演示数据。

### OGE 平台 `whu-cultivated_land`

- 适用于武汉一号融合影像的耕地提取模型，可快速形成候选区基线。
- 优点是无需自行上传模型，能够直接体现 OGE 数据、模型和算力协同。
- 局限是只识别耕地，不能将结果直接称为水稻分布。

## 暂不进入主线

### semanticricefield

- MIT 许可，U-Net 结构简单，输入为 Sentinel-2 RGB。
- 仓库中的 U-Net 权重文件实际为空，不能直接部署。
- 可参考其切片和网络结构，但需要重新准备武汉一号样本并训练。

### TerraSegNet / Plot-Rice

- MIT 许可，仓库提供 Plot-Rice 推理脚本和外部预训练权重链接。
- 模型环境要求较高，且训练数据与武汉一号影像存在传感器和区域域差异。
- 作为第二阶段候选模型保留，在拿到稳定样本后再做对比，不阻塞业务闭环。

## 采用原则

当前版本先完成“武汉一号影像—耕地候选区—统计单元面积—分阶段参考需水—关注等级”的可运行链路。水稻专用识别作为可替换模块，待 OGE 平台样本和产品参数核验后再升级。
