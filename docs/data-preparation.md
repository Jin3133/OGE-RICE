# 数据准备与清洗执行方案

## 1. 首版最小数据集

首版算法开发只依赖四类核心数据：

1. 同一瓦片、覆盖关键生育阶段的 Sentinel-2 L2A 影像；
2. 可用于裁剪和统计的示范区边界；
3. 区域作物历与分阶段灌溉定额；
4. 与分析阶段一致的气象降水数据。

训练样本和独立验证样本属于水稻识别的必需数据，应按空间分区隔离。武汉一号影像、
历史面积和实际取供水台账属于增强数据，不阻塞首版流程。

## 2. 当前遥感数据基线

- 产品：`S2_MSIL2A`；
- 目标瓦片：`T50RKU`；
- 目标范围：武汉区域候选框 `113.8–114.8°E, 29.8–31.0°N`；
- 筛选条件：2025 年水稻种植季，目录云量不高于 20%；
- 已验证场景：`T50RKU_20250501T030529`；
- 优先候选：`T50RKU_20250816T025529`、`T50RKU_20251005T025529`。

目录云量只用于初筛。正式入选还需检查示范区内的有效像元比例、局地云与云影、波段
完整性和几何一致性。

## 3. 清洗顺序

1. 确定示范区边界并完成几何检查；
2. 用边界重新评价每景影像，而不是只采用整景云量；
3. 统一影像数值尺度、波段名称、像元网格和无效值掩膜；
4. 按生育阶段生成单景候选或阶段合成影像；
5. 清洗训练与验证样本，并完成空间隔离；
6. 统一作物历、灌溉定额和气象数据的区域与时间口径；
7. 生成可复现的数据版本号和质量报告后再进入算法开发。

## 4. 入库门槛

- 影像可在 OGE 开发中心读取；
- 场景覆盖示范区，且分析区内有效观测达到项目设定阈值；
- 影像产品、场景编号、采集日期、云量和处理状态记录完整；
- 边界几何有效、编号唯一、来源和年份明确；
- 作物历阶段连续且无重叠；
- 分阶段灌溉定额单位为立方米每亩，并有适用区域、阶段和来源；
- 缺失值与有效零值严格区分。

## 5. 当前阻塞项

当前最关键的缺口不是影像数量，而是尚未确定示范区边界、样本和正式分阶段灌溉定额。
只有确定示范区后，才能对目录中的候选影像进行真正的局地云量和有效覆盖清洗。
武汉一号开发计算权限仍受限，暂作为增强项保留。
