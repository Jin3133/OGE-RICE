# DeepLabV3+ 第三轮模型推理记录

## 1. 推理对象

- 模型：DeepLabV3+。
- 编码器：ResNet-50，使用 ImageNet 预训练初始化后微调。
- Checkpoint：第三轮验证集 IoU 最优的 `best.pt`。
- 数据：`oge_farm_v2` 独立测试集，共 82 景。
- 输入：512×512、3 波段、uint16 TIFF。
- 无效像元：三个波段同时为 0 的位置不参与指标计算。
- 二值化阈值：0.70，由验证集阈值扫描确定。

## 2. 全局结果

| 指标 | 结果 |
|---|---:|
| IoU | 0.7049 |
| F1 | 0.8269 |
| Precision | 0.8243 |
| Recall | 0.8296 |
| Accuracy | 0.8857 |

测试集单样本 IoU 分布：最小值 0.0203，25% 分位数 0.5958，中位数 0.7091，75% 分位数 0.8293，最大值 0.9312。

## 3. 代表性案例解读

可视化按“原始影像、人工标签、模型预测、误差图”排列。误差图颜色含义如下：

- 绿色：正确识别的耕地（TP）；
- 橙色：模型误判为耕地（FP）；
- 红色：模型漏检的耕地（FN）；
- 深灰色：正确识别的背景（TN）；
- 黑色：无效像元。

最差样本主要集中在城乡混合、厂房与道路附近，以及标签面积较小的场景。模型容易把具有相似纹理或光谱表现的非耕地区域识别为耕地；部分样本则表现为大块目标漏检，提示训练数据可能包含较强的区域、时相或地物外观差异。

中位样本通常能够识别主体地块，误差主要集中在地块边缘、道路、林带和零碎地块。最佳样本对大块规则农田、田间分隔线和内部非耕地孔洞处理较好，IoU 可超过 0.91。

## 4. 推理产物

推理目录为 `outputs/inference/deeplabv3plus_epoch3_test/`，包括：

- `probabilities/*.tif`：uint16 概率图，0～65535 对应概率 0～1；
- `predictions/*.tif`：uint8 二值分割结果；
- `per_sample_metrics.csv`：逐样本指标和前景比例；
- `representative_cases.jpg`：最差、中位和最佳案例汇总；
- `visualizations/*.jpg`：单个代表性样本的四联图；
- `inference_summary.json`：模型哈希、代码版本、阈值、运行设备、耗时和全局指标。

## 5. 阶段结论

当前模型已经可以作为耕地分割基线和业务流程验证模型。总体指标较稳定，但样本间差异明显，后续不宜只依赖总体 IoU。下一步应优先检查最差样本的标签和场景类型，并增加按场景分组的评价；用于水稻业务时，还必须补充水稻专用标签或物候时序信息，不能将当前耕地预测直接解释为水稻分布。
